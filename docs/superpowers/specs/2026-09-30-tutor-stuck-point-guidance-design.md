# Fourier Tutor 卡点定位引导设计

## 目标

当学生的问题无法直接定位学习障碍时，在问答区插入一张轻量选择卡，帮助学生说明自己卡在哪里。卡片提供三个上下文相关的选项、自由输入，以及“还分不清，带我从头看”的兜底入口。

## 首版范围

首版只解决“定位卡点”，不把每次回答都变成选择题，也不在学生已经明确指出卡点时再次追问。卡片属于问答消息流的一部分，不使用阻断式全屏弹窗。

示例：学生说“我不懂卷积”时，显示：

1. 不理解它在算什么——想先弄懂卷积的意义
2. 看不懂图上的操作——翻转、平移、重叠让我困惑
3. 理解大概意思，但不会算题——不知道怎么列积分

另有自由文本输入和“还分不清，带我从头看”。选项不预选、不标注推荐答案。

## 触发规则

- 问题明确包含知识点或操作时，直接回答，不显示卡片。例如“为什么要把 h(τ) 翻转？”
- 问题模糊、学生明确表示不懂，或同一处连续追问仍无法定位时，显示卡片。
- 一次卡片提交后，Tutor 必须依据选择或自由文本改变回答起点；不能只重复一段通用解释。
- 同一轮定位完成后，不连续弹出另一张定位卡；后续可以用普通教学问题检查理解。
- 卡片和学生原始问题、选择结果都保留在对话记录中。

## 交互与数据

卡片提交产生结构化上下文：原始问题、触发原因、选项 ID 或自由文本、时间戳。Tutor 请求将该上下文作为本轮教学意图输入。兜底选项映射为“从概念直觉开始，并逐步确认理解”，而不是当作一个具体知识点。

自由输入为空时不能提交；键盘支持 Tab / 上下键选择，Enter 或空格确认，符合现有对话区的可访问性习惯。提交后卡片进入已完成状态，避免重复点击。

## 教学原则

选项要短、互斥性尽量高、覆盖常见卡点，但允许学生自行描述。选择用于确定讲解入口，不用于给学生贴永久标签，也不应暗示哪个答案正确。后续版本可以在已定位后加入“引导思考”问题，但不纳入首版。

## 验收标准

- 明确问题不会触发卡片。
- “我不懂卷积”能显示三个卷积相关选项、自由输入和兜底入口。
- 选择任一选项后，Tutor 回答明确围绕该卡点展开。
- 自由输入会被传给 Tutor 并影响回答。
- 原问题、卡片和回答在消息流中保持可见。
- 卡片不阻断其他问答功能，且不会在同一轮重复出现。
