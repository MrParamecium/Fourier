2.4-2 · Graphical Understanding of Convolution Operation

这一小节把上一节的积分变成“看得见的操作”。目标不是每个时刻都画一张图，而是掌握一套可以重复的移动、重叠、求面积流程。

本节目标：给定一个时刻 t，能画出被积的两条曲线；能指出重叠区；能把重叠面积写成卷积在该时刻的一个输出值。

学习路线：先读懂教材图，再用四步按钮操作同一组函数，最后用三个例题检查“重叠区决定积分限”。

1. 为什么需要图形卷积

教材给出的三个理由可以压缩成三句话：

  • 处理复杂信号：信号难以直接写成或计算成公式时，图形能帮助我们评估积分。
  • 看清结果：把卷积结果画出来，有助于理解采样、滤波等问题中的形状。
  • 没有精确公式时仍能工作：有些信号只能用图描述；两个这样的信号卷积时，只能用图形方法。

2. 先固定观察时刻：t 是参数

教材用 x(t) 和 g(t) 说明流程：

\[c(t)=x(t)*g(t)=\int_{-\infty}^{\infty}x(\tau)g(t-\tau)\,d\tau\]

计算某个 t=t_0 时，真正要画的是 x(τ) 和 g(t_0−τ)，两条曲线都以 τ 为横轴。x(τ) 与 x(t) 形状相同；g(τ) 与 g(t) 形状相同。改变的是第二条曲线的位置，不是积分变量的名字。

3. 一帧图的五步读法

1. 固定 x(τ)，不要让它跟着移动。 2. 从 g(τ) 开始，关于 τ=0 做时间反转，得到 g(−τ)。 3. 沿 τ 轴移动 t_0，得到 g(t_0−τ)；t_0>0 向右，t_0<0 向左。 4. 只看两条曲线的重叠区：乘积 x(τ)g(t_0−τ) 的面积就是 c(t_0)。 5. 改变 t_0，重复这套操作，把每个面积放到 c(t) 的对应位置，连成整条结果曲线。

先做一个最小检查：如果移动后的曲线和固定曲线完全没有重叠，乘积在所有位置都为零，因此这一帧的卷积值就是零。

图里的颜色只用来区分角色：蓝色是固定的 x(τ)，橙色是移动后的 g(t_0−τ)，紫色是乘积。真正决定结果的是重叠范围和面积，不是颜色。

4. 例 2.10：两个因果函数

例题取 x(t)=e^{-t}u(t)、h(t)=e^{-2t}u(t)，与例 2.8 相同，但这次强调图形步骤。

  • t<0：左移后的 h(−τ) 与 x(τ) 不重叠，所以 y(t)=0。
  • t≥0：重叠区是 0≤τ≤t，乘积面积为 ∫_0^t x(τ)h(t−τ)dτ。
  • 代入并化简得到 y(t)=(e^{-t}-e^{-2t})u(t)。

这里“先判重叠，再写积分限”比一上来展开指数更重要。

做题顺序固定为：先画支撑区 → 再找交集 → 最后才代入函数表达式。

5. 例 2.11：因果函数与双边函数

教材设 x(t)=u(t)，并把双边的 g(t) 分成两段：

\[g(t)=2e^{-t}\ (t\ge 0),\qquad g(t)=-2e^{2t}\ (t<0)\]

为了让分段更简单，固定 x(τ)=1，只追踪 g(t−τ) 的两段何时落入重叠区。

  • t≥0：A 段覆盖 0<τ<t，B 段覆盖 t<τ<∞，所以 c(t)=∫_0^t2e^{-(t-τ)}dτ+∫_t^∞-2e^{2(t-τ)}dτ=1-2e^{-t}。
  • t≤0：重叠区只包含 B 段，所以 c(t)=∫_0^∞-2e^{2(t-τ)}dτ=-e^{2t}。

最终结果是：

\[c(t)=1-2e^{-t}\ (t\ge 0),\qquad c(t)=-e^{2t}\ (t\le 0)\]

这题训练的是“同一条移动曲线跨过不同分段时，积分表达式要随重叠区改变”。

6. 例 2.12：两个有限持续时间函数

这里 x(t) 是宽度为 2 的矩形，g(t)=\frac13t 只在 0≤t≤3 有效。教材选择反转更简单的 x(t)，计算 g(t)*x(t)。

移动 x(−τ) 后，边缘位于 τ=-1+t 和 τ=1+t。随着 t 增大，重叠边界依次改变，因此结果分三段：

  • −1≤t<1：重叠为 0≤τ≤1+t，c(t)=\frac16(t+1)^2。
  • 1≤t<2：重叠为 −1+t≤τ≤1+t，c(t)=\frac23t。
  • 2≤t<4：重叠为 −1+t≤τ≤3，c(t)=−\frac16(t^2−2t−8)。
  • 其他时间没有重叠，c(t)=0。

边界检查：在 t=1，前两段都给 c(1)=2/3；在 t=2，后两段都给 c(2)=4/3。没有冲激时，卷积在这些转换点应保持连续。

7. 把“看起来很复杂”变成固定动作

教材的完整流程可以缩成一条链：

固定 x(τ) → 反转 g(τ) → 平移到 g(t_0−τ) → 找重叠 → 对乘积求面积 → 改变 t_0 重复。

利用交换律，优先反转数学描述更简单的信号。就像搬家时先搬轻箱子：目标没变，但每一步更省力。

现在只记住

  • 卷积的一个输出点 = 一帧重叠乘积的面积。
  • 没有重叠，卷积就是零。
  • 有限宽度信号的结果宽度等于两者宽度之和。

本节必须掌握：不看公式也能口述“固定—反转—平移—重叠—求面积—重复”，并能用这条链解释例 2.10、2.11、2.12 的分段范围。
